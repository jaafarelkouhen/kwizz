# Mathématiques

## Calcul et puissances
Les tables de multiplication : 7 × 8 = 56, 6 × 7 = 42, 9 × 9 = 81. Les puissances de 2 : 2^5 = 32, 2^8 = 256, 2^10 = 1024. Un carré parfait : 12² = 144, donc la racine carrée de 144 est 12. Un pourcentage : 25 % de 80 = 80 × 25 / 100 = 20.

## Nombres premiers
Un nombre premier a exactement deux diviseurs distincts : 1 et lui-même. 2, 3, 5, 7, 11, 13 sont premiers ; 1 n'est pas premier (un seul diviseur) ; 21 = 3 × 7 n'est pas premier. 2 est le seul nombre premier pair.

## Équations du premier degré
Pour résoudre 2x + 3 = 11 : on soustrait 3 des deux côtés (2x = 8), puis on divise par 2 (x = 4). On vérifie toujours en remplaçant : 2 × 4 + 3 = 11.

## Identités remarquables
Développer (a + b)² donne a² + 2ab + b² ; (a − b)² = a² − 2ab + b² ; (a + b)(a − b) = a² − b². Erreur classique : (a + b)² n'est pas égal à a² + b².

## Second degré
Pour ax² + bx + c = 0, le discriminant vaut Δ = b² − 4ac. Si Δ > 0 il y a deux solutions x = (−b ± √Δ) / 2a ; si Δ = 0 une solution double −b / 2a ; si Δ < 0 aucune solution réelle. Exemple : x² − 5x + 6 donne Δ = 25 − 24 = 1, solutions 2 et 3.

## Géométrie
La somme des angles d'un triangle vaut 180°. Théorème de Pythagore : dans un triangle rectangle, hypoténuse² = somme des carrés des deux autres côtés ; avec 3 et 4 on obtient √(9 + 16) = 5. Aire d'un disque : πr² ; périmètre d'un cercle : 2πr ; la valeur approchée de π (le nombre pi) est 3,14 (plus précisément 3,14159). Un hexagone a 6 côtés, un pentagone 5, un octogone 8.

## Dérivées
La dérivée mesure la pente (vitesse de variation) d'une fonction. (x^n)' = n·x^(n−1), donc (x²)' = 2x et (x³)' = 3x². (sin x)' = cos x ; (cos x)' = −sin x ; (e^x)' = e^x ; (ln x)' = 1/x. La dérivée d'une constante vaut 0.

## Résoudre une équation du second degré : méthode
Une équation du second degré s'écrit ax² + bx + c = 0 avec a non nul. Méthode : 1) repérer a, b et c ; 2) calculer le discriminant Δ = b² − 4ac ; 3) si Δ > 0, deux solutions (−b − √Δ) / 2a et (−b + √Δ) / 2a ; si Δ = 0, une seule solution −b / 2a ; si Δ < 0, pas de solution réelle. Exemple : x² − 5x + 6 = 0, a = 1, b = −5, c = 6, Δ = 25 − 24 = 1, solutions (5 − 1)/2 = 2 et (5 + 1)/2 = 3.

## Fractions et proportionnalité
Pour additionner deux fractions, on les met au même dénominateur : 1/2 + 1/3 = 3/6 + 2/6 = 5/6. Pour multiplier, on multiplie numérateurs et dénominateurs : 2/3 × 3/4 = 6/12 = 1/2. Deux grandeurs sont proportionnelles quand on passe de l'une à l'autre en multipliant toujours par le même nombre ; le produit en croix permet de trouver une valeur manquante.

## Probabilités
La probabilité d'un événement est un nombre entre 0 (impossible) et 1 (certain). Quand toutes les issues sont équiprobables : nombre de cas favorables divisé par le nombre de cas possibles. Exemple : obtenir un 6 avec un dé équilibré a une probabilité de 1/6.
