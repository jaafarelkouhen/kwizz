# Glossaire

| Terme | Définition |
|-------|------------|
| Quizz | Série de questions à choix proposée aux utilisateurs inscrits. |
| Question | Énoncé accompagné d'au moins deux choix, dont au moins un correct. |
| Choix | Réponse possible à une question, marquée correcte ou non. |
| Tentative | Passage d'un quizz par un utilisateur à une date donnée, avec un score. |
| Historique | Liste des tentatives d'un utilisateur. |
| Administrateur | Utilisateur autorisé à créer, importer et supprimer des quizz. |
| Product Owner | Membre de l'équipe qui gère le projet et sert d'interface avec le commanditaire. |
| Sprint | Période de travail courte (ici une séance) avec un objectif livrable. |
| User story (US) | Besoin exprimé du point de vue d'un utilisateur : « En tant que…, je veux… ». |
